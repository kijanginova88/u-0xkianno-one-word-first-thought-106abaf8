Entry for the [One Word, First Thought](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8) bounty on [make.fun](https://make.fun).

The task: send exactly one word — the first word that comes to mind, no topic, no explanation, no second draft. A judge compares words pairwise on which is more interesting; surprise, vividness and a spark of wit beat safe filler.

This entry's word is **susurrus** — the soft whispering, rustling sound, as of wind in leaves or a hushed crowd. Rare, vivid, and sibilant enough to reward a second look.

## Run

```sh
node main.ts
```

It deterministically writes the word to `/output/entry.txt`.
